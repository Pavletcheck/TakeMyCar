# TakeMyCar

Браузерная 3D-игра в духе GTA 2: вид сверху, живой город, угон машин, трафик,
пешеходы, полиция, миссии. Three.js + TypeScript + Vite.

**Играть:** https://pavletcheck.github.io/TakeMyCar/

Статус: **M0 — pre-alpha**. Есть каркас, серый город и машина с аркадной физикой.
Игровых систем (трафик, копы, миссии, UI) пока нет — они в M3–M6.

## Быстрый старт
```bash
npm install
npm run dev        # http://127.0.0.1:5173
npm run typecheck
npm run build      # dist/
npm run deploy     # сборка + публикация на GitHub Pages
```

## Управление (pre-alpha)
- WASD / стрелки — газ, тормоз, руль.
- Пробел — ручник.
- R — вернуть машину на старт.

## Документы
- `AGENTS.md` — правила проекта, роли, гигиена процессов, деплой.
- `docs/CONCEPT.md` — концепт и рамки.
- `docs/ROADMAP.md` — этапы и критерии приёмки.
- `docs/releases/` — релиз-ноты по этапам.
- `промпты/00_MASTER.md` — мастер-бриф для агентов.
- `промпты/01..10` — брифы по зонам ответственности.
- `.opencode/agents/` — конфигурации подагентов (бригада).

## Платформы
1. Яндекс Игры — основной релиз.
2. VK Игры — адаптер через VK Bridge.
3. Обычный браузер / itch.io — демо и портфолио.
