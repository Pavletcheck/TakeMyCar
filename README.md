# TakeMyCar

Браузерная 3D-игра в духе GTA 2: вид сверху, живой город, угон машин, трафик,
пешеходы, полиция, миссии. Three.js + TypeScript + Vite.

Статус: **этап 0 — организация проекта**. Код ещё не начат.

## Быстрый старт (после этапа 1)
```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # dist/
npm run typecheck
```

## Документы
- `AGENTS.md` — правила проекта, роли, гигиена процессов.
- `docs/CONCEPT.md` — концепт и рамки.
- `docs/ROADMAP.md` — этапы и критерии приёмки.
- `промпты/00_MASTER.md` — мастер-бриф для всех агентов.
- `промпты/01..09` — брифы по зонам ответственности.
- `.opencode/agents/` — конфигурации подагентов (бригада).

## Платформы
1. Яндекс Игры — основной релиз.
2. VK Игры — адаптер через VK Bridge.
3. Обычный браузер / itch.io — демо и портфолио.

## Управление
- Десктоп: WASD/стрелки, пробел — ручник, E — войти/выйти, ЛКМ — огонь, Q — камера.
- Мобильные: виртуальный стик, газ/тормоз, ручник, действие, огонь.
