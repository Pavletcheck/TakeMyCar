# M3 — процедурный город

Версия: 0.4.0
Дата: 2026-11-24
Ссылка: https://pavletcheck.github.io/TakeMyCar/

## Что сделано
- Город вынесен из `app/bootstrap.ts` в `src/world/**` и стал процедурным.
- **Мир 1200×1200 м**, 3 района: центр (высотки), промзона (склады, заборы),
  набережная (парк, вода).
- **Детерминизм**: решения по кварталам от `hash2(seed, ix, iz)`, содержимое от
  локального `createRng`; порядок стриминга на планировку не влияет.
  `layoutHash` (FNV-1a): seed 20261123 → `7ccee86d`, seed 777 → `eb4baf99`.
- **Дорожный граф**: 121 узел, 420 направленных рёбер, 20 односторонних,
  16 светофоров, проверка связности, JSON-экспорт/импорт, геометрия полос
  (`laneWidth`, `laneOffsets`, `lanePoint`).
- **Чанки 128 м**: зона 5×5 вокруг игрока, генерация/выгрузка, единый аллокатор
  положительных id, insert/remove статики в общем SpatialHash.
- **Рендер** `src/render/cityView.ts`: ≤3 InstancedMesh на чанк, общие материалы,
  culling, `dispose()`.
- **Отладка**: `?seed=N` меняет весь мир; `?debug=1` показывает чанки, `gen max`,
  `layoutHash`, счётчики и `window.__tmc` (`teleport`, `carState`, `exportRoadGraph`).
- **Стресс-режим** `?stress=1` перебазирован на новые границы мира.
- `assets/maps/road-graph.json` — снимок графа для отладки.

## Известные проблемы
- Высокие здания могут перекрывать машину при фиксированной камере (окклюзия) —
  лечится в M6 (поворот/наклон камеры или fade).
- Вода — плоская плоскость без берега и пены (M7).
- Стресс-режим может поставить куб на пути машины сразу после старта — это
  ожидаемое поведение debug-режима, не баг.
- Коллайдеров в HUD теперь зависит от активных чанков (417 → 376 → 268),
  прежний эталон M2 (24/374) не действует; QA нужен новый baseline.
- Мобильный fps не проверялся; камера/туман настроены под блоки 100 м (M6).
