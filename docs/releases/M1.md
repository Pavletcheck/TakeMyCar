# M1 — каркас и цикл

Версия: 0.2.0
Дата: 2026-11-23
Ссылка: https://pavletcheck.github.io/TakeMyCar/

## Что сделано
- Монолит `src/main.ts` (404 строки) разложен на модули:
  `core/{math,rng,loop,input,spatialHash,events,camera}` и `app/{bootstrap,debug}`.
- `main.ts` — 4 строки: стили + `bootstrap()`.
- Фиксированный шаг 60 Гц, интерполяция позиции машины, защита от спирали смерти.
- Пауза на `blur` / `visibilitychange`, сброс ввода и накопителя без скачка dt.
- Коллизии машины с домами через `SpatialHash` (сетка 8 м), без перебора всех коллайдеров.
- Отладочный HUD: fps, frame ms, draw calls, tris, colliders.
- Режим `?stress=1` — 300 невидимых статических коллайдеров для проверки бюджета.
- Архитектура: `docs/ARCHITECTURE.md`, ADR 0001–0003, ревью `docs/reviews/M1-main-review.md`.

## Как проверить
1. Открыть ссылку, дождаться исчезновения загрузки.
2. WASD/стрелки — езда, пробел — ручник, R — сброс.
3. Добавить `?stress=1` к URL — в HUD `colliders 324`.
4. Свернуть/развернуть вкладку — симуляция замирает и продолжается без рывка.

## Известные проблемы
- Мобильного управления и мыши/геймпада нет (M2/M6).
- Решатель коллизий в один проход, скорость при ударе ×0.25 (итерации и restitution — M2).
- Город всё ещё строится в `app/bootstrap.ts`, без `World`/чанков (M3).
- 404 `favicon.ico` закрыт инлайн-иконкой.
- FPS в headless-тестах недостоверен (SwiftShader); бюджет проверять на GPU.
