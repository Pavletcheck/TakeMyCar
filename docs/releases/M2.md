# M2 — физика, реестр сущностей, пулы

Версия: 0.3.0
Дата: 2026-11-24
Ссылка: https://pavletcheck.github.io/TakeMyCar/

## Что сделано
- **Решатель коллизий** (`core/collision.ts`): 3 итерации разрешения контактов,
  restitution 0.2, трение касательной, антитуннелирование дроблением пути
  (подшаг ≤ 0.4 м, максимум 8). Circle-vs-OBB и Rect-vs-Rect через SAT.
- **Исправлен баг OBB** (A-08 из аудита QA): в `circleRect` был прямой поворот вместо
  обратного — нормали зеркалились относительно меша.
- **`EntityRegistry`** (`core/registry.ts`): generational id, компоненты
  Transform / Collider / RenderRef, `create/destroy/query/queryMask/each`,
  отложенный `flush()` — безопасное удаление посреди итерации.
- **`ObjectPool`** (`core/pool.ts`): O(1) release, без роста capacity после прогрева.
- **Динамические коллайдеры** живут в общем `SpatialHash`: insert/update/remove,
  отрицательные id отделяют их от статики; утечек нет (20 000 циклов create/destroy).
- **SpatialHash**: поддержка `angle` (мировой AABB для OBB), пустые bucket'ы
  переиспользуются, запросы без аллокаций.
- **HUD**: `frame ms`, `logic ms`, `overrun`, `debt`, `entities`, `colliders (dyn N)`.
- **Стресс-режим** `?stress=1`: 300 статических кубов + 50 движущихся (видимые),
  кинематика через `resolveRectBody` против статики.
- **Конфиг** `src/config/tuning.ts`: fixedStep, maxSubsteps 5, maxFrameDelta 0.25,
  итерации, restitution, трение, размер ячейки, количество тел.
- Скорость в HUD считается после разрешения удара; `R` сбрасывает скорость и камеру.
- Из публичных текстов убрано слово «GTA» (требование модерации).

## Известные проблемы
- Пауза — один флаг, без набора причин (`PauseReason`); актуально для рекламы на платформах.
- Нет `destroy()` приложения: слушатели и GPU-ресурсы не освобождаются при перезапуске.
- Тач-ввода нет (M6).
- `logicMs` использует `performance.now()` в логике — только для диагностики.
- На старте возможен `overrun` из-за компиляции шейдеров (единичный, виден в HUD).
- Стресс-статика неподвижна; движущихся тел 50, а не 300.
