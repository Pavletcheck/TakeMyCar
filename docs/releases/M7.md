# M7 — low-poly модели и интеграция

Версия: 0.8.0
Дата: 2026-11-24
Ссылка: https://pavletcheck.github.io/TakeMyCar/

## Что сделано
- **5 машин** в Blender 5.3 (headless): sedan, sports, van, truck, police.
  960–1084 tris LOD0, 284–396 LOD1 (30–39 %), GLB, vertex colors, пивот в центре,
  forward +Z.
- **Персонажи**: пешеход 532 tris, коп 600 tris, части с пивотами (torso/head/arms/legs),
  «far»-LOD 36 tris. Без скиннинга.
- **16 пропсов**: фонари, урны, гидранты, деревья, скамейки, билборды, заборы.
- **Кит зданий**: стена, угол, крыша, парапет, вывеска (36–212 tris) — пока не подключён.
- **Интеграция** `src/render/**`:
  - `modelLibrary` — один GLTFLoader, кэш, общие материалы `vertexColors + flatShading`,
    пути через `import.meta.env.BASE_URL` (работает на Pages).
  - `vehicleView` — GLB по типу, LOD1 дальше 42 м, покраска узла `paint`,
    fallback на примитивы для каждой машины.
  - `npcView` — инстансинг частей, шаг/наклон/падение матрицами, LOD1 дальше 32 м.
  - `playerView` — модель игрока; `cityView` — GLB-пропсы одним инстанс-сетом.
  - `?models=0` — принудительный fallback без GLB.
- Blender-пайплайн: `tools/blender/*.py` + `inspect_glb.mjs` (tris, габариты, пивот).
- README: `tools/blender/README.md`, `assets/models/README.md`.

## Известные проблемы
- Дома пока коробки: китовые модули не подключены к `world`/`cityView` (M7.1).
- Текстуры: готов только асфальт (512, бесшовный), остальные генерируются.
- LOD-порог заметен на ортокамере при резком телепорте; в движении не читается.
- Персонажи без скелетной анимации: покачивание/падение кодом.
- Пики `overrun` на старте из-за декодирования GLB (единичные).
