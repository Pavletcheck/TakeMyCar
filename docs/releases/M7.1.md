# M7.1 — low-poly дома вместо коробок

Версия: 0.8.1
Дата: 2026-11-24
Ссылка: https://pavletcheck.github.io/TakeMyCar/

## Что сделано
- **4 готовых дома** в Blender (`bld_block_small/mid/tall`, `bld_tower`):
  392–584 tris LOD0, 72 tris LOD1, пивот по центру основания, forward +Z.
- Внутри моделей: цоколь, уступы, ленты окон, простенки, парапет, крыша с выходом,
  кондиционеры, вентиляция, бак у высоток, вывески, козырёк и вход.
- **Интеграция `cityView`**: выбор по высоте, масштаб под w/d/h мира,
  LOD0 ближе 90 м, LOD1 дальше, отсечка 160 м, инстансинг по бакетам.
  Fallback на коробки при `?models=0` и ошибке загрузки; коллайдеры не менялись.
- Контраст крыш усилен (0.54 → 0.46), кровля читается сверху.
- README обновлены: tris домов, сборка, бюджеты.

## Известные проблемы
- Узкие промышленные кварталы (43 дома) растягивают рисунок окон — нужен отдельный
  «складской» бакет (M7.2).
- Текстуры сгенерированы (15 шт.), но ещё не подключены к сцене (M7.2).
- Пики загрузки моделей на старте дают `overrun` в HUD (единичные).
- На встроенном браузере OpenCode WebGL-контекст может не создаваться; проверка
  идёт через headless Chrome с GPU.
