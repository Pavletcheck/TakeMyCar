# M0 — организация проекта и первый деплой

Версия: 0.1.0
Дата: 2026-11-23
Ссылка: https://pavletcheck.github.io/TakeMyCar/

## Что сделано
- Структура проекта, `AGENTS.md`, концепт и роадмап.
- Брифы `промпты/00..10` и 11 подагентов в `.opencode/agents/`.
- Каркас Vite + TypeScript + Three.js.
- Pre-alpha демо: серый город 5×5 кварталов, дорожная разметка, машина с аркадной
  физикой (газ, тормоз, руль, ручник, задний ход), коллизии с домами, следование камеры.
- Деплой на GitHub Pages через ветку `gh-pages`.

## Как проверить
1. Открыть ссылку, дождаться исчезновения «Загрузка города…».
2. WASD — машина едет, пробел — занос, R — сброс.
3. В HUD: fps, скорость, draw calls, треугольники.

## Известные проблемы
- Мобильного управления нет (появится в M6).
- Трафика, пешеходов, полиции и миссий нет (M3–M6).
- Город серый, ассетов из Blender нет (M7).
- Нет звука (M6–M7).
