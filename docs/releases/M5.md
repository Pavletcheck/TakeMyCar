# M5 — жизнь города, полиция и оружие

Версия: 0.6.0
Дата: 2026-11-24
Ссылка: https://pavletcheck.github.io/TakeMyCar/

## Что сделано
- **Трафик** (`systems/traffic.ts`): движение по полосам дорожного графа, светофоры,
  дистанция и объезд, уступание сирене, спавн/деспавн за кадром, лимит 60.
- **Пешеходы** (`systems/peds.ts`): маршруты по периметру кварталов и переходы,
  состояния idle/walk/alert/flee/panic/down, паника от выстрела/сигнала/сирены,
  сбивание машиной, лимит 200.
- **Розыск** (`systems/wanted.ts`): heat 0–5, звёзды, остывание, патруль → погоня →
  блокпост → перехват, спавн копов, PIT/таран, пешие копы, арест, стрельба по игроку.
- **Оружие** (`systems/combat.ts`): пистолет/ПП/дробовик, хитскан, магазин/запас,
  перезарядка, разброс/отдача, трассеры и искры. Без крови.
- **HUD**: звёзды розыска, HP, оружие и патроны; подсказки управления.
- **Отладка**: `wanted()`, `setWanted(n)`, `trafficStats()`, `pedStats()`,
  `spawnCop()`, `combatState()`, `copShots/copHits/nearestCar`.
- Рендер: `npcView` (пешеходы/копы, падение), `effectsView` (трассеры/искры).

## Проверка
| Проверка | Результат |
|---|---|
| `typecheck` / `build` | зелёные |
| Трафик | 60 машин, avg 3–5 м/с, 20 с — без пробки |
| Пешеходы | 200, ходят; выстрел → flee/panic |
| Стрельба игрока | 3 выстрела → розыск 1, патроны тратятся |
| Стрельба копов | 6 выстрелов → 5 попаданий, HP машины 100→58, HP игрока 100→72 |
| Розыск | 3 → копы приезжают за 4–6 с, heat держится |
| Браузер | 144 fps, 43–52 draw calls, <1 мс update, 0 ошибок консоли |

## Исправлено по ходу
- Копы не стреляли по игроку из машины (самостолкновение с кузовом) — добавлен ignore
  своего коллайдера и урон по кузову.
- Розыск улетал на 5 из-за тарана копами — теперь heat растёт только если игрок сам
  въехал в копа.
- Копы отставали на другом конце карты — добавлен аркадный догон (30–45 м за кадром).
- Лимит копов 9 > 8 исправлен; дистанция деспавна согласована с чанками.
- Урон копов сделан вероятностным: углы и трафик больше не «съедают» все пули.

## Известные проблемы
- Копы могут появляться в 35–55 м и иногда в кадре — M5.1.
- При включении розыска 3 сразу спавнится много машин, возможна пробка — M5.1.
- Скрытность по LOS отключена для heat (копы «знают» позицию в радиусе 140 м);
  укрытие работает только по дистанции.
- Разовые пики `update` до ~12 мс (GC), устойчиво <1 мс.
- HUD «vehicles» показывает весь флот, а не только трафик.
