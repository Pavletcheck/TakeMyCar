## 1. Область

### В области (M3)
1. **Детерминизм генерации:** один seed → один layout; seed не зависит от порядка
   обхода чанков, вьюпорта, DPR и качества.
2. **Дорожный граф:** узлы/рёбра/полосы/ограничения/тупики, связность, сериализация
   в JSON и обратная загрузка (`промпты/03_WORLD.md:11,22,35`).
3. **Стриминг чанков 128 м:** активация/выгрузка вокруг игрока, отсутствие утечек
   коллайдеров, мешей, геометрий и материалов.
4. **Совпадение коллайдеров с мешами** (регресс R-09 и A-08r: физика не должна
   расходиться с картинкой).
5. **Геометрия мира:** дороги, тротуары, вода/набережная, районы (центр, промзона,
   набережная), пропсы и их размещение вне проезжей части.
6. **API полос для трафика** и **данные мини-карты** — как данные, без ИИ и HUD.
7. **Отладочные входы:** `?seed=N`, `?debug=1` (и совместимость с `?stress=1`).
8. **Бюджеты:** чанк < 8 мс, 60 fps, draw calls < 150, tris < 200k, стабильное число
   коллайдеров при движении, размер бандла.
9. **Статические правила кода:** Three только в `render`/`app`, `world` без DOM,
   ноль аллокаций в кадре, `Rect`/`Collider` только из `core/math.ts`.

### Вне области (проверяется только на отсутствие регрессий)
Трафик, пешеходы, полиция (M5); миссии, экономика, HUD, мини-карта как UI, сохранения,
мобильные контролы (M6); GLB-модели, текстуры, LOD (M7); SDK площадок (M8).
Для M3 «регресс» = «новая сцена города не ломает загрузку, езду, паузу, `R`,
`?stress=1` и счётчики HUD».

## 3. Приёмочные кейсы M3

### 3.1 Детерминизм

**Алгоритм layout hash (QA-предложение, фиксируется до реализации).**
Хэш считается по каноническому списку целых чисел: все вещественные поля умножаются
на 1000 и округляются (`Math.round(v * 1000)`), углы — тоже (радианы × 1000).
Порядок записей — только сортировка, никогда порядок `Map`/обхода:

1. `seed`;
2. чанки по возрастанию `(cx, cz)`; для каждого — коллайдеры по возрастанию `id`:
   `x, z, hx, hz, angle`;
3. здания/пропсы: тип, `x, z, w, d, h`, индекс палитры (по возрастанию `id`);
4. узлы графа по `id`: `x, z, kind, lights?1:0`;
5. рёбра, отсортированные по `(from, to, lanes)`: `lanes, speed, oneWay`;
6. точки спавна: `x, z, heading`, код тега.

Свёртка — FNV-1a 32-bit по десятичным строкам чисел. Хэш **не** включает: время,
`activeChunks`, счётчики fps, порядок генерации чанков, вьюпорт, DPR, настройки
качества, данные стресс-режима.

| ID | Кейс | Ожидание | Приоритет |
|---|---|---|---|
| DET-01 | Открыть `?seed=20261123`, записать `layoutHash`; F5 ×5 | все 6 значений совпали, `chunks`, `colliders`, `props` тоже совпали | P0 |
| DET-02 | `?seed=1` и `?seed=2` | `layoutHash` различается; при этом каждый повторяем | P0 |
| DET-03 | Один seed: заезд из центра и старт с дальнего угла (или прямой вызов генерации чанков в обратном порядке) | `layoutHash` одинаков: он не зависит от порядка активации чанков | P0 |
| DET-04 | `?seed=abc`, `?seed=-5`, `?seed=0`, `?seed=999999999999`, `?seed=` | нет падения и белого экрана; задокументированное поведение (fallback / clamp / консольное предупреждение); при `abc` — дефолтный seed | P1 |
| DET-05 | `grep -rn "Math.random\|Date.now\|performance.now" src/world src/core` | в `src/world/**` 0 совпадений; в `src/core/**` только разрешённое (сейчас — `loop.ts` и диагностика) | P0 |

Важно: HUD `logic ms` — **среднее за 0.5 с** (`src/app/debug.ts:57-79`). Одиночный

принимается **только** по счётчику максимума (`M3-AUDIT.md` M3-A-16); без него кейс
CH-07 — `BLOCKED`, а не PASS.
