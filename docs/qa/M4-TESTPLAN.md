## 1. Область

### В области (M4)
1. **Пять типов машин** (седан, спорткар, фургон, грузовик, полицейская): разгон,
   максимальная скорость, руление, дрифт, задний ход; различия читаются на ощупь и по числам.
2. **Вход/выход `E`**: радиус, свободное место, запрет входа в занятую и уничтоженную машину.
3. **Урон**: удары и `hp`, дым при низком `hp`, взрыв без крови, ремонт; строка HUD обновляется.
4. **Пеший режим**: 8 направлений, коллизии, камера.
5. **Спавн машин** на точках карты, полицейская — у участка.
6. **Коллизии**: не проваливается, не застревает, не туннелирует на 30 м/с.
7. **Бюджеты**: 60 fps, 8 машин + город, физика < 2 мс, draw calls < 150.
8. **Регресс M2/M3**: spatial hash, чанки, вода/мост, стресс-режим, пауза, `R`, HUD.

### Вне области (проверяется только на отсутствие регрессий)
Трафик, пешеходы, розыск 0–5 и копы-ИИ (M5); миссии, экономика, меню, мини-карта как UI,
сохранения, мобильные контролы, локализация (M6); GLB-модели машин и LOD (M7);
SDK площадок (M8). Явно **не тестируем** из `промпты/04_VEHICLES.md:39-42`: реалистичную
трансмиссию, сцепление, подвеску на лучах, ИИ трафика, рисованные модели.

1. Метрика «0–100 км/ч» из M2 непригодна: van физически не едет быстрее 90 км/ч,

// e2e/vehicles.spec.ts — создаётся владельцем platform/core после одобрения зависимости
const BASE = process.env.BASE_URL ?? 'http://127.0.0.1:4173/TakeMyCar/';

test('машина едет, дрифтует и сбрасывается', async ({ page }) => {
  const errors: string[] = [];
  page.on('console', (m) => { if (m.type() === 'error') errors.push(m.text()); });
  page.on('pageerror', (e) => errors.push(String(e)));
  await page.goto(BASE);
  await expect(page.locator('#loading')).toHaveClass(/hidden/, { timeout: 5000 });

  await page.keyboard.down('KeyW');
  await page.waitForTimeout(1500);

  await page.waitForTimeout(800);
  await page.keyboard.up('KeyA');
  await page.keyboard.up('KeyW');
  await page.keyboard.press('KeyR');
  await expect(page.locator('#stats')).toContainText(/speed 0 km\/h/);

Главные выводы:

1. **Машина уже есть, но как «игрок-заглушка».** `player` = машина, коллайдера нет,
   `kind` нет. Первым делом — две сущности (`player`, `vehicle`), у машины коллайдер
   в общем hash и фильтр самостолкновения (M4-A-01/02/06).
2. **Урон не из чего строить без одного чтения.** `damageVehicle` уже написан, но
   `solveResult.impact` по-прежнему не читается (M4-A-03) — это самый дешёвый вход в DM-*
   и звук `crash`.
3. **HUD — узкое место приёмки.** Нет `hp`/типа/режима и нет максимума физики
   (M4-A-23/24). Без этих двух полей половина кейсов §4 не принимается числом.
4. **Стресс-режим сейчас врёт** (BUG-M4-001): счётчик коллайдеров правильный,
   положение тел — нет. Все «стресс проходит» до фикса недействительны.
5. **Спавн валидируется радиусом 0.6 при радиусе машины 1.77–2.78** (M4-A-16) —
   типовой источник «машина появилась в стене» и «выход в стену».
6. **Два дефекта конфига/логики уже на стадии без запуска:** грузовик не достигает
   своей `maxSpeed` (BUG-M4-002), стресс-movers уезжают от игрока (BUG-M4-001).
   Оба ловятся арифметикой — не надо ждать браузера.

## 13. Порядок прогона

1. `npm run typecheck` → `npm run build`; сверить размер бандла и наличие
   `src/systems/**` и подключения `VehicleFleet` в `bootstrap`.
2. Статические проверки: `grep` по числам типов, `ActionName`, `physMaxMs`, `hp` в HUD,
   отсутствие `Math.random`/`console.log` в новых модулях.
3. Арифметика конфига до браузера: `v_eq = (accel − 2.2)/0.55` против `maxSpeed` для всех
   типов (сейчас ловит BUG-M4-002), `R = maxSpeed/steerRate`, `damageScale`, `τ = 1/grip`.
4. Офлайн-проверки на данных: 8 car-точек + `cop`-точки × 5 типов → `circleRect` с радиусом
   типа. Дешевле всего и сразу закрывает SP-01/SP-03/SP-04 (SP-03 уже известен: 55 м).
5. Локально `npm run preview` (порт 4173): VT, EN, DM, ON, CL по порядку §4.
6. Живая сборка + E9/E10: HUD-числа, `__tmc.carState()`, `stats()`.
7. E11/E12 (гараж, мост), E13 (throttle), E15 (слепой тест).
8. Стресс + 8 машин 60 с; **сначала** подтвердить/опровергнуть BUG-M4-001.
9. Итог: `docs/qa/runs/M4-<дата>.md` (сэмплы, дефекты), обновление этого файла
   (статусы), закрытие рисков §11 в отчёте, короткий отчёт прорабу.
