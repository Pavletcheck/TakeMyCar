## 0. Обозначения

| Символ | Значение |
|---|---|
| ✅ PASS | подтверждено живым прогоном или воспроизводимой статической проверкой |
| ❌ FAIL | расхождение с требованием; блокирует приёмку этапа |
| ⚠️ принято | Low/Medium, зафиксирован, не блокирует M6 |

## 1. Область

### В области (M6)
1. **Миссии:** data-driven, три типа, телефон-пейджер, маркер цели, таймер, успех/провал,
   награда, кулдаун, повторное взятие, провал по `heatOnFail`.
2. **Экономика:** деньги, ремонт, покраска (сброс розыска), апгрейды, баланс в
   `config/economy.json`, сохранение прогресса.
3. **HUD:** деньги, HP, звёзды, скорость, оружие/патроны, цель; читаемость на 360×640;
   отсутствие дублей HP/звёзд после миграции `lifeHud`.
4. **Мини-карта:** дороги/кварталы/вода, игрок, копы, маркер миссии, масштаб и поворот.
5. **Пауза/меню/настройки/язык:** Esc и кнопка, набор причин паузы, настройки звука и
   управления, смена языка без перезагрузки.
6. **Сохранение/загрузка:** версия схемы, localStorage + `PlatformAdapter.save`,
   переживание F5, отказ хранилища, миграция.
7. **Мобильное управление:** виртуальный стик, газ/тормоз, ручник, действие, огонь,
   safe area, отсутствие на десктопе.
8. **Локализация:** ru/en/tr без хардкода, `Intl` для чисел, отсутствие обрезанного текста.
9. **Звук:** звук UI/миссий и mute, автоплей-политика браузеров.
10. **Бюджеты:** 60 fps, UI не блокирует canvas, draw calls/память, 30-минутный соак.
11. **Регресс M2–M5:** физика, карта, стресс, пауза, `R`, `E`, розыск, оружие, HUD-числа.

### Вне области (проверяется только на отсутствие регрессий)
Модели и текстуры (M7), SDK Яндекс/VK, реклама, лидерборды (M8), трейлер/портфолио (M9),
сюжет и катсцены (`06_MISSIONS_UI.md:48`), рисование иконок вручную (`:49`),
новые типы оружия/машин, банды, интерьеры.

## 3. Конфиги и данные M6: обязательные поля и инварианты

Числа баланса задаёт `ui`, QA проверяет **наличие полей, согласованность и отсутствие
литералов в логике** (`AGENTS.md:47`). Значения ниже — предложения для согласования.

### 3.1 Миссии (`config/missions.json`)

| Поле | Инвариант |
|---|---|
| `id` | уникален, стабильный (используется в сохранении и кулдауне) |
| `type` | ровно три используемых: `deliver` (довези), `steal` (угон и пригони), `timed` (разбей за время); неизвестный тип — ошибка старта, а не тихий пропуск |
| `titleKey`, `descKey` | ключи словаря, **не текст** (`06:37`) |
| `start`, `target` | координаты в метрах в границах карты; `target` достижим транспортом либо явно помечен «пешком» (§11.1 BUG-M6-001) |
| `targetRadius` | > 2 м и ≤ 20 м; маркер не пересекается со зданием |
| `timeLimit` | > 0 для `timed`; `null`/отсутствует для остальных |
| `reward` | > 0; для `timed` растёт с сложностью, но не превышает разумный потолок из `economy.json` |
| `heatOnFail` | 0..5; провал не поднимает heat выше потолка |
| `cooldown` | ≥ 0 с; кулдаун переживает сохранение/загрузку |
| `conditions.vehicleClass` | из `config/vehicles.ts` (`sedan`, `sports`, `van`, `truck`, `police`) |
| `conditions.noDamage` | bool; при провале причина `'wrecked'` либо `'abandoned'` — не «timeout» |

Проверки: валидация в dev обязательна (`ARCHITECTURE.md:509-512`); дубли `id` —
ошибка старта; `NaN`/отрицательный `reward` — ошибка.

### 3.2 Экономика (`config/economy.json`)

| Поле | Инвариант |
|---|---|
| `startMoney` | ≥ 0, целое |
| `missionRewardScale` | > 0; итог = `mission.reward · scale`, округление вниз |
| `repair.costPerHp` | ≥ 0; цена = доля HP · коэффициент, не «фикс за всё» |
| `repair.minCost` | ≥ 0 и ≤ `repair.costPerHp · 100` |
| `paint.cost`, `paint.heatReset` | > 0; покраска сбрасывает heat в 0 **и** гасит погоню по правилу §4.2 |
| `upgrades[]` | `id`, `cost`, `effect`, `maxLevel`; эффекты не ломают физику (`maxSpeed` +≤ 20 %) |
| `crimeFine` (если есть) | ≥ 0; списание не уводит деньги в минус |
| `moneyFormat` | ключ локали `Intl`, валюта без внешних данных (`06:38`) |

Проверки: `grep` цен только в конфиге; отрицательный баланс невозможен; покупка при
недостатке денег не меняет состояние (ни деньги, ни апгрейд, ни heat).

### 3.3 UI (`config/ui.json`) и локализация (`assets/i18n/**`)

| Поле | Инвариант |
|---|---|
| `hud.updateHz` | 5–20 Гц; не каждый кадр |
| `hud.safeArea` | учитывает `env(safe-area-inset-*)`, не «12px на всё» |
| `minimap.size`, `minimap.zoomSteps` | ≥ 2 шага; игрок всегда в центре или на краю с индикатором |
| `colors.*` | из палитры проекта; контраст текста ≥ 4.5:1 на фоне HUD |
| `mobile.stickRadius`, `mobile.deadzone` | deadzone 0.1–0.2; радиус ≥ 56 CSS px (палец) |
| `mobile.alwaysThrottle` | bool, по умолчанию `false` (`06:34`) |
| `i18n.default`, `i18n.fallback` | `ru`/`en`; отсутствующий ключ падает в fallback и **не** печатает ключ в UI |
| словари | одинаковый набор ключей в ru/en/tr; ключи плоские (`06:37`), без конкатенации |

### 3.4 Сохранение

| Поле | Инвариант |
|---|---|
| `version` | целое, начинается с 1; поле обязательно (`ARCHITECTURE.md:407-410`) |
| `profile.money`, `upgrades`, `cooldowns`, `settings{lang,volumes,mute,mobile}` | есть всегда, значения валидируются на загрузке |
| миграция | чистая функция `migrate(vN → vN+1)`; неизвестная будущая версия → безопасный дефолт, не падение (`ARCHITECTURE.md:734-736`) |
