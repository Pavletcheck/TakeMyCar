## 1. Область

### В области (M5)
1. **Трафик:** полосы дорожного графа, дистанция, светофоры, приоритет на
   перекрёстках, объезд препятствий, реакция на игрока и сирены, лимит 60,
   спавн/деспавн за кадром, дальний упрощённый тик.
2. **Пешеходы:** тротуары, переходы, маршруты по графу/периметру кварталов,
   состояния `idle → walk → alert → flee → panic`, реакции на сигнал, удар,
   выстрел, погоню и взрыв, лимит 200, без ragdoll.
3. **Розыск:** heat 0–5, звёзды, таймер остывания, укрытие/потеря видимости,
   уровни «патруль → погоня → блокпост → перехват».
4. **Копы:** спавн на узлах дорог за кадром, погоня по графу, PIT/таран,
   спешивание, пешие копы, стрельба, арест при остановке.
5. **Оружие:** три типа (пистолет, ПП, дробовик), патроны, перезарядка, урон,
   хитскан + трассер, без крови и брендов.
6. **Бюджеты:** 200 пешеходов + 60 машин + 8 копов < 4 мс на шаг, 60 fps,
   draw calls < 150, отсутствие аллокаций в апдейте, темп спавна ≤ 1 раза в 0.5 с.
7. **Регресс M2–M4:** физика и 5 типов машин, вход/выход `E`, карта/стриминг,
   вода и мост, стресс-режим, пауза, `R`, HUD, отладочный API, консоль и сеть.

### Вне области (проверяется только на отсутствие регрессий)
Миссии, экономика, HUD как продукт (звёзды/спидометр/мини-карта), меню, пауза-меню,
сохранения, мобильные контролы, локализация (M6); GLB-модели людей и LOD (M7);
SDK Яндекс/VK, реклама (M8); трейлер и портфолио (M9).

Явно **не тестируем** из брифа: банды и сюжет (`05_LIFE_AI.md:43`), реалистичную
баллистику, кровь/расчленёнку, интерьеры, транспортные средства сверх 5 типов.
«Регресс» здесь = «новые системы не ломают загрузку, езду, вход/выход, карту,
воду, паузу, `R`, стресс и счётчики HUD».

```ts
// e2e/life.spec.ts — создаётся владельцем platform/core после одобрения зависимости
const BASE = process.env.BASE_URL ?? 'http://127.0.0.1:4173/TakeMyCar/';

test('канвас стартует, жизнь города инициализирована без ошибок', async ({ page }) => {
  const errors: string[] = [];
  const bad: string[] = [];
  page.on('console', (m) => { if (m.type() === 'error') errors.push(m.text()); });
  page.on('pageerror', (e) => errors.push(String(e)));
  page.on('response', (r) => { if (r.status() >= 400) bad.push(`${r.status()} ${r.url()}`); });

  await page.goto(`${BASE}?debug=1`);
  await expect(page.locator('#loading')).toHaveClass(/hidden/, { timeout: 5000 });
  await expect(page.locator('#game canvas')).toHaveCount(1);
  const box = await page.locator('#game canvas').boundingBox();
  expect(box?.width ?? 0).toBeGreaterThan(100);

  const life = await page.evaluate(() => window.__tmc!.lifeState());
  expect(life.peds).toBeGreaterThan(0);
  expect(life.peds).toBeLessThanOrEqual(200);
  expect(life.traffic).toBeLessThanOrEqual(60);
  expect(life.heat).toBe(0);

  await page.keyboard.down('KeyW');
  await page.waitForTimeout(2000);
  await page.keyboard.up('KeyW');
  await expect(page.locator('#stats')).toContainText(/speed [1-9]\d* km\/h/);

  expect(errors).toEqual([]);
  expect(bad).toEqual([]);
});

test('событие розыска приходит один раз на изменение', async ({ page }) => {
  await page.goto(`${BASE}?debug=1`);
  await expect(page.locator('#loading')).toHaveClass(/hidden/, { timeout: 5000 });
  const levels = await page.evaluate(async () => {
    const seen: number[] = [];
    window.__tmc!.onWantedChanged((level) => seen.push(level));
    window.__tmc!.debugCrime('shot');
    await new Promise((r) => setTimeout(r, 500));
    return seen;
  });
  expect(levels).toEqual([1]);
});
```

Главные выводы:

1. **Владение обновлением — риск №1.** `step()` и цикл по `fleet.list` уже заняты
   игроком и физикой; без решения «кто двигает трафик-машину» будет двойная
   интеграция, двойной урон и пропуски при `splice` (M5-A-01/02/15).
2. **Слоёв коллизий нет.** Пешеход в общем хэше — препятствие для машины, а
   `moveCircle` не исключает собственное тело. Это надо решить до наполнения
   города, иначе наезд на пешехода будет «ударом в стену» (M5-A-09/10).
3. **Лимит 60/200/8 не обеспечен ничем, кроме дисциплины.** `VehicleFleet` без
   cap, `vehicleView` на 96, пул сущностей растёт. Нужны проверки в спавнере и
   счётчики в `lifeState()` (M5-A-15/16/27).
4. **Спавн «за кадром» и «не в стене» сейчас невозможен через публичный API.**
   `querySpawnPoints` проверяет 0.6 м (BUG-M5-002), фрустум недоступен системам
   (M5-A-19/20). Это два самых дешёвых фикса до кода M5.
5. **HUD-звёзды — конфликт зон.** Бриф `life` запрещает HUD, ROADMAP требует
   звёзды. Приёмку M5 надо строить на `wanted:changed`/`lifeState()`, а DOM-звёзды
   отдать `ui` в M6 (M5-A-25/26).
6. **Игрок и оружие стоят на пустом месте.** Нет hp игрока, режима ареста,
   действий `fire/aim`, линии видимости (M5-A-32/33/34). Это не «доделать в M5»,
   а явные задачи `core`/`life` до приёмки.
7. **Переходов нет в данных.** Требование «пешеходы на переходах» не на чем
   строить: `cityView` рисует только полосы, `sidewalks` — плиты (M5-A-40).
