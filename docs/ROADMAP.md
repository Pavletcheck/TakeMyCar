# TakeMyCar — роадмап

Статусы: `[ ]` не начато, `[~]` в работе, `[x]` готово, `[!]` заблокировано.

**Правило этапа:** каждый этап заканчивается деплоем на GitHub Pages
(https://pavletcheck.github.io/TakeMyCar/), релиз-нотами `docs/releases/M<N>.md`
и тегом `m<N>`. Без живой ссылки этап не принимается.

## M0. Организация (текущий)
- [x] Папка проекта, AGENTS.md, концепт, роадмап.
- [x] Брифы в `промпты/`, конфиги подагентов.
- [x] Каркас Vite + TS + Three и первый деплой на Pages (pre-alpha).
- [ ] Заказчик утверждает концепт и рамки.
- Критерий: заказчик сказал «поехали».

## M1. Каркас и цикл
Владелец: `core`. Статус: `[x]` (v0.2.0).
- [x] Vite + TS + Three, сцена, ортокамера, свет, серый пол.
- [x] Фиксированный шаг 60 Гц, интерполяция рендера, пауза при потере фокуса.
- [x] Ввод по карте действий (клавиатура), отладочный HUD (fps, frame ms, draw calls, tris, colliders).
- [x] Модули `core/*` и `app/*`, spatial hash, режим `?stress=1` на 300 коллайдеров.
- Критерий выполнен: город ездит по WASD, 17 draw calls, сборка и деплой зелёные.
- Осталось на M2: мышь/геймпад/тач, решатель с итерациями, реестр сущностей и пулы.

## M2. Физика и коллизии
Владелец: `core`.
- OBB/AABB/circle, spatial hash, решатель столкновений, тряска камеры.
- Реестр сущностей и пулы.
- Критерий: 300 объектов сталкиваются без просадок.

## M3. Город
Владелец: `world`.
- Seeded-генератор: кварталы, дороги, тротуары, разметка, пропсы.
- Дорожный граф с полосами и узлами, точки спавна.
- Стриминг чанков 128 м, коллизии зданий, данные для мини-карты.
- Критерий: город 1.2×1.2 км, генерация без фризов, езда по дорогам.

## M4. Машины
Владелец: `vehicle`.
- Аркадная модель, дрифт, ручник, задний ход, повреждения, дым, взрыв без крови.
- Вход/выход, 5 типов машин, тюнинг-конфиги, звук двигателя.
- Критерий: приятно ездить, столкновения читаемы, нет застреваний.

## M5. Жизнь и полиция
Владелец: `life`.
- Трафик по полосам, светофоры, объезд, сигналы.
- Пешеходы: маршруты, испуг, паника.
- Розыск 0–5: спавн копов, погоня, PIT, пешие копы, укрытия.
- Критерий: 200 пешеходов + 60 машин + погоня при 60 fps.

## M6. Миссии, UI, мобилка
Владелец: `ui`.
- Data-driven миссии: «довези», «угон», «разбей за время».
- Телефон-пейджер, деньги, ремонт/покраска/апгрейды, сохранение.
- HUD: здоровье, звёзды, мини-карта, спидометр. Меню, пауза, настройки.
- Мобильные контролы, safe area, локализация ru/en/tr.
- Критерий: полная петля игры на телефоне и десктопе.

## M7. Арт
Владельцы: `art3d`, `textures`.
- Кит-баш зданий, 5 машин, персонажи, пропсы, LOD, атласы.
- Текстуры из ComfyUI, ретушь, палитра, бесшовность.
- Критерий: единый стиль, бюджеты tris/draw calls соблюдены.

## M8. Платформа
Владелец: `platform`.
- Адаптер платформы: Web / Yandex / VK.
- SDK: init, ready, gameplay start/stop, пауза, реклама, player data, лидерборды.
- Сборка-архив, проверка модерации, размер, HTTPS, оффлайн-кэш.
- Критерий: билд проходит чек-лист Яндекса и VK.

## M9. Полировка и портфолио
Владельцы: `qa`, прораб.
- Баланс, звук, музыка, экраны загрузки, туториал.
- Профилирование, автотесты смоука, исправление багов.
- Трейлер, скриншоты, кейс-стади, itch.io-зеркало.
- Критерий: релиз-кандидат + пакет для портфолио.

## Риски
1. Модерация из-за криминальной темы → стилизация, рейтинг 12+/16+, без крови.
2. Мобильный fps → LOD, инстансинг, бюджеты, раннее тестирование на телефоне.
3. Расползание скоупа → один район, три миссии, никаких интерьеров.
4. SD-генерации съедают время → только текстуры и билборды, геометрия в Blender.
