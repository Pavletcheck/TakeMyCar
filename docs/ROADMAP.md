# TakeMyCar — роадмап

Статусы: `[ ]` не начато, `[~]` в работе, `[x]` готово, `[!]` заблокировано.

**Правило этапа:** каждый этап заканчивается деплоем на GitHub Pages
(https://pavletcheck.github.io/TakeMyCar/), релиз-нотами `docs/releases/M<N>.md`
и тегом `m<N>`. Без живой ссылки этап не принимается.

## Риски
1. Модерация из-за криминальной темы → стилизация, рейтинг 12+/16+, без крови.
2. Мобильный fps → LOD, инстансинг, бюджеты, раннее тестирование на телефоне.
3. Расползание скоупа → один район, три миссии, никаких интерьеров.
4. SD-генерации съедают время → только текстуры и билборды, геометрия в Blender.
