# TakeMyCar — правила проекта

## Что это
Браузерная 3D-игра в духе GTA 2: вид сверху, открытый город, угон машин, трафик,
пешеходы, полиция и уровень розыска, миссии. Низкополигональный стиль, Three.js.
Цель: портфолио + публикация на Яндекс Играх (основная) и в VK Играх (адаптер).

## Роли
- **Заказчик** — пользователь. Принимает решения по продукту, смотрит демо, утверждает этапы.
- **Прораб** — главный агент (эта сессия). Декомпозирует, ставит задачи, ревьюит, собирает,
  запускает тесты, отвечает за качество и сроки. Не пишет весь код сам, а раздаёт подагентам.
- **Бригада** — подагенты из `.opencode/agents/`. Каждый работает по своему брифу из `промпты/`.
- **Релиз** — каждый завершённый этап выкладывается на GitHub Pages, ссылка уходит заказчику.

## Стек (не менять без ADR)
- TypeScript, Vite, Three.js (ортографическая камера сверху, логика в плоскости XZ).
- Физика своя, аркадная: OBB/AABB/circle + spatial hash. Без Rapier/Cannon на старте.
- Состояние: лёгкий реестр сущностей + системы (не полноценный ECS).
- Детерминизм: seeded RNG (mulberry32) для генерации города.
- Аудио: WebAudio, синтез + сэмплы. Ассеты только свои или CC0.
- Никаких внешних запросов в рантайме: всё бандлится. CDN запрещён (требование платформ).
- Локализация: ru / en / tr (JSON-словари), строки не хардкодить.

## Структура (целевая)
```
src/
  main.ts            — точка входа
  app/               — bootstrap, платформенный адаптер, настройки
  core/              — цикл, ввод, математика, RNG, пулы, spatial hash
  world/             — генератор города, дорожный граф, стриминг чанков
  entities/          — игрок, машины, пешеходы, копы, снаряды
  systems/           — физика, трафик, ИИ, розыск, миссии, экономика
  render/            — Three-сцена, инстансинг, материалы, LOD, камера
  ui/                — HUD, мини-карта, меню, мобильные контролы
  audio/             — движок, шины, выстрелы, музыка
assets/              — glb, текстуры, звуки (генерируются скриптами)
tools/               — blender/, sd/, build/ скрипты
docs/                — концепт, роадмап, ADR, платформенные требования
промпты/             — брифы задач для подагентов
```

## Правила работы
1. Перед задачей агент читает `AGENTS.md`, `промпты/00_MASTER.md` и свой бриф.
2. Один агент — одна зона ответственности. Не редактировать чужие файлы без согласования с прорабом.
3. Любое изменение — маленькими шагами, рабочая сборка после каждого шага (`npm run build` + `npm run typecheck`).
4. Нет мёртвого кода, `any` без причины, `console.log` в финальных ветках.
5. Все числа баланса и тюнинга — в JSON/TS-конфигах, не в логике.
6. Комментарии и документация — по-русски; идентификаторы — по-английски.
7. Не использовать IP Rockstar: названия, машины, музыку, логотипы, карту. Жанр свободен.
8. Контент: стилизованное насилие без крови и расчленёнки, без наркотиков и реальных брендов —
   иначе модерация Яндекс Игр и VK завернёт.

## Гигиена процессов и кэша (обязательно)
- Агент не оставляет за собой фоновые процессы: сервер, ComfyUI, blender, playwright —
  всё либо в foreground, либо с сохранённым PID и явным `Stop-Process` в конце.
- Перед запуском нового подагента прораб закрывает процессы предыдущего этапа.
- После батча генераций в ComfyUI: удалить `ComfyUI/temp/*`, удалить из `Data/Images` только
  файлы с префиксом `tmc_`, ненужные промежуточные варианты. Финальные текстуры копируются в
  `assets/textures/` и только они попадают в репозиторий.
- Не удалять чужие файлы пользователя. Всё вне папки проекта — только чтение.
- `node_modules`, `dist`, `outputs`, `.cache`, `*.blend1` — в `.gitignore`.

## Деплой после каждого этапа (обязательно)
- Репозиторий: `Pavletcheck/TakeMyCar` (публичный). Ветка `main` — исходники,
  ветка `gh-pages` — собранный `dist`.
- Живая ссылка: https://pavletcheck.github.io/TakeMyCar/
- Деплой: `npm run deploy` (сборка + публикация через `gh-pages`).
- Этап не считается закрытым, пока ссылка не открывается на десктопе и телефоне.
- Версия, тег `m<N>` и релиз-ноты в `docs/releases/M<N>.md` — часть этапа.
- CI-воркфлоу подготовлен в `docs/ci/deploy-workflow.yml`; включится после
  `gh auth refresh -s workflow` (сейчас у токена нет scope `workflow`).
- Подробности и откат: `промпты/10_RELEASE.md`, агент `release`.

## Definition of Done
- `npm run typecheck` и `npm run build` проходят.
- Игра запускается, фича проверена вручную/скриптом, нет регрессий в соседних системах.
- Бюджеты: 60 fps на десктопе (1080p), ≥30 fps на среднем телефоне; draw calls < 150, tris < 200k.
- Обновлены `docs/ROADMAP.md` (статус) и, при необходимости, ADR.
- Этап задеплоен на GitHub Pages, деплой успешен, ссылка проверена, есть релиз-ноты.
- Прораб получает короткий отчёт: что сделано, чем проверено, что осталось, какие риски.

