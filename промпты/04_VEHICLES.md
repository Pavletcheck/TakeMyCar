# 04 — Машины и управление (vehicle)

## Миссия
Сделать так, чтобы ездить было приятно: отзывчивый руль, предсказуемый дрифт,
читаемые столкновения, разные характеры машин. Зона — `src/entities/vehicle.ts`,
`src/systems/vehiclePhysics.ts`, `config/vehicles.json`.

## Модель (аркадная, без коробки передач)
- Состояние: позиция, курс, продольная/поперечная скорость, угловая скорость.
- Газ/тормоз → ускорение; сопротивление воздуха; ограничение максималки.
- Руление зависит от скорости (на месте не крутится).
- Боковое трение: высокое на асфальте, низкое на ручнике → дрифт.
- Ручник: сброс сцепления задней оси, занос, следы шин.
- Задний ход после полной остановки.
- Столкновения: импульс по нормали, потеря скорости, искры, тряска камеры.

## Конфиг (пример)
```json
{
  "sedan": { "mass": 1200, "accel": 8.0, "maxSpeed": 28, "steer": 2.4, "grip": 7.5,
             "brake": 14, "drift": 2.2, "hp": 100, "seats": 4 }
}
```

## Выход
- 5 типов: седан, спорткар, фургон, грузовик, полицейская машина.
- Вход/выход (E), анимация двери не нужна — телепорт игрока с проверкой места.
- Повреждения: hp, дым при <30%, взрыв без крови, ремонт в гараже (хук для `ui`).
- Звук: хук `engine:onRpm(rpm)`, `skid:onSlip(v)`, `crash:onImpact(power)`.
- Камера: упреждение по скорости, отъезд при разгоне, тряска при ударе.
- Следы шин и частицы — пул, не создавать объекты каждый кадр.

## Критерий приёмки
- Круг по кварталу: разгон, поворот, ручник, разворот, задний ход — без застреваний.
- 60 машин одновременно, физика < 2 мс.
- Ни одна машина не «проваливается» в дом и не дрожит на месте.
- Ощущение: спорткар нервный, седан спокойный, фургон валкий.

## Не делать
- Не делать реалистичную трансмиссию, сцепление, подвеску на лучах.
- Не писать ИИ трафика — только API для него (`getLane`, `getSpeed`, `setInput`).
- Не рисовать модели — это `art3d`.
