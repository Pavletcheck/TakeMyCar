# 06 — Миссии, интерфейс, мобилка (ui)

## Миссия
Связать системы в игру: цель, награда, интерфейс, управление на телефоне.
Зона — `src/systems/missions.ts`, `src/systems/economy.ts`, `src/ui/**`, `src/app/save.ts`,
`assets/i18n/**`.

## Миссии (data-driven)
```ts
type Mission = {
  id: string; type: 'deliver'|'steal'|'timed';
  title: string; desc: string;
  start: [number, number]; target: [number, number];
  timeLimit?: number; reward: number; heatOnFail: number;
  conditions?: { noDamage?: boolean; vehicleClass?: string };
};
```
- 3 типа: «довези», «угон и пригони», «разбей за время».
- Телефон-пейджер: список доступных, звонок, таймер, провал/успех.
- Случайные события: угнанная машина, погоня, гонка (опционально).

## Экономика
- Деньги за миссии, угон, трюки. Траты: ремонт, покраска (сброс heat), апгрейды.
- Баланс в `config/economy.json`. Сохранение: localStorage + `PlatformAdapter.save`.

## HUD и меню
- Здоровье, броня, звёзды розыска, деньги, мини-карта, спидометр, подсказки.
- Меню: пауза, настройки (звук, графика, управление), выбор языка.
- Читаемость на 360×640: крупные элементы, safe area, без мелкого текста.

## Мобильное управление
- Виртуальный стик (слева), газ/тормоз (справа), ручник, действие, огонь.
- Автоподстройка под ориентацию; блокировка зума и контекстного меню.
- Опция «газ всегда» для аркадного режима.

## Локализация
- `ru`, `en`, `tr`; ключи плоские, без конкатенации строк.
- Числа/валюта через `Intl`, но без внешних данных.

## Критерий приёмки
- Полная петля: взял заказ → доехал → получил деньги → потратил → сохранился.
- Игра проходится на телефоне без клавиатуры.
- Переключение языка без перезагрузки; нет обрезанного текста.
- 60 fps с HUD на десктопе, ≥30 на телефоне.

## Не делать
- Не писать ИИ и физику — только события и API.
- Не делать сюжетные катсцены и диалоги.
- Не рисовать иконки вручную — SVG-примитивы или атлас от `art3d`.
