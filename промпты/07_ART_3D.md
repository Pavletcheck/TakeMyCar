# 07 — 3D-арт и Blender (art3d)

## Миссия
Единый low-poly стиль и оптимизированные ассеты. Зона — `assets/models/**`,
`assets/materials/**`, `tools/blender/**`, `src/render/**` (интеграция и материалы).

## Blender
- Версия: 5.3 (`C:\Program Files (x86)\Steam\steamapps\common\Blender\blender.exe`).
- Работа только через headless-скрипты:
  `blender.exe --background --python tools/blender/build_cars.py`
- Скрипты детерминированы, без ручных правок в UI; результат — `.blend` (в `.gitignore`)
  и экспорт `.glb` в `assets/models/`.

## Ассеты (приоритет)
1. Машины: седан, спорткар, фургон, грузовик, полицейская. 800–1500 tris, 1 материал.
2. Персонажи: игрок, 4 пешехода, коп. 400–900 tris, общий скелет, 2–3 анимации (idle/walk/run/fall).
3. Здания: модульный кит — стены, углы, крыши, парапеты, вывески. Собираются в `world`.
4. Пропсы: фонарь, урна, гидрант, дерево, скамейка, билборд, барьер.
5. Спецэффекты: искры, дым, следы шин — спрайты/частицы, не геометрия.

## Стиль
- Плоские цвета + запечённый AO, без PBR-карт кроме basecolor/roughness.
- Крупные формы, скругления минимальны, читаемость сверху.
- Палитра из `docs/CONCEPT.md`; текстуры 256–512 px.
- Никаких логотипов и реальных марок. Номера и надписи — вымышленные.

## Экспорт
- GLB + отдельный LOD1 (≤40% tris), pivot в центре, масштаб 1 unit = 1 m,
  Y-up после экспорта, forward — +Z (оговорить с `core`).
- Материалы: 1–2 на объект, без прозрачности кроме стёкол.
- Имена: `car_sedan_lod0.glb`, `ped_cop_lod0.glb`, `bld_wall_a.glb`.

## Интеграция (Three)
- `InstancedMesh` для машин/пропсов/зданий, `MeshLambertMaterial`/`MeshStandardMaterial` c
  `flatShading`.
- Один directional light + hemisphere, тени только у игрока и ближних объектов.
- Атлас/общие материалы, чтобы draw calls < 150.
- Загрузка: GLTFLoader, прогресс → `PlatformAdapter.reportProgress`.

## Критерий приёмки
- Все ассеты собираются одной командой из чистого репозитория.
- Сцена с городом и 60 машинами — 60 fps, бюджеты соблюдены.
- Визуально единый стиль, нет «фотореализма вперемешку с кубами».

## Не делать
- Не генерировать текстуры в Blender — это `textures`.
- Не расставлять город — это `world`.
- Не анимировать сложный скелет (IK, лицевые) — не нужно.
