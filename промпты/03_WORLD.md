# 03 — Город и стриминг (world)

## Миссия
Генерировать город, по которому приятно ездить: кварталы, дороги, тротуары, пропсы,
дорожный граф и данные для мини-карты. Зона — `src/world/**`, `assets/maps/**`.

## Выход
- `generator.ts` — seeded-генерация 1.2×1.2 км: сетка кварталов, магистрали, переулки,
  парк, промзона, набережная. Разные типы застройки.
- `chunks.ts` — нарезка на чанки 128 м, стриминг вокруг игрока, выгрузка далёких.
- `roadGraph.ts` — узлы, рёбра, полосы, ограничения скорости, светофоры, точки спавна.
- `props.ts` — фонари, урны, гидранты, деревья, билборды, скамейки; коллизии только у крупных.
- `minimap.ts` — упрощённая геометрия дорог и кварталов для HUD.
- `spawn.ts` — точки спавна машин/пешеходов/копов, валидация «не в стене».

## Формат данных
```ts
type RoadNode = { id: number; x: number; z: number; kind: 'cross'|'t'|'dead'; lights?: boolean };
type RoadEdge = { from: number; to: number; lanes: number; speed: number; oneWay: boolean };
type Chunk = { cx: number; cz: number; colliders: Collider[]; meshes: number[]; props: Prop[] };
```
Граф сериализуется в JSON, генератор детерминирован по seed.

## Правила
- Генерация чанка < 8 мс; тяжёлое — заранее или в idle.
- Никаких дыр в дорожном графе: каждая дорога связна, тупики помечены.
- Дома — коробки с крышами и парапетами, без интерьеров.
- Визуал кварталов — через инстансинг; один материал на тип.
- Данные для мини-карты обновляются при стриминге, не каждый кадр.

## Критерий приёмки
- Город 1.2×1.2 км, 3 района, езда по всем дорогам без застреваний.
- На карте читаются кварталы, магистрали, вода/парк.
- 60 fps при стриминге на десктопе, ≥30 на мобилке.
- Экспорт графа в JSON и обратная загрузка для отладки.

## Не делать
- Не расставлять миссии и трафик — это `life` и `ui`.
- Не генерировать текстуры — это `textures`.
- Не строить LOD-систему — это `art3d`/`render`.
