# 00 — Мастер-бриф (читать перед любой задачей)

Ты — часть бригады, которая делает **TakeMyCar**: браузерную 3D-игру в духе GTA 2
(вид сверху, открытый город, угон машин, трафик, пешеходы, полиция, миссии).
Заказчик — пользователь. Прораб — главный агент. Ты — исполнитель по своей зоне.

## Обязательный контекст
1. `AGENTS.md` — правила проекта и Definition of Done.
2. `docs/CONCEPT.md` — что за игра и что в неё не входит.
3. `docs/ROADMAP.md` — текущий этап и критерии приёмки.
4. Твой бриф `промпты/0X_*.md`.

## Стек
- TypeScript (strict), Vite, Three.js, ортокамера сверху, логика в плоскости XZ.
- Своя аркадная физика: OBB/AABB/circle + spatial hash. Без внешних физических движков.
- Лёгкий реестр сущностей и системы; не тащить ECS-фреймворк.
- Все ассеты локальные. В рантайме — ноль внешних запросов (CDN, шрифты, API).
- Конфиги баланса — JSON/TS, не хардкод в логике.
- Локализация ru/en/tr через словари.

## Бюджеты
- Десктоп 1080p: 60 fps. Мобилка средняя: ≥30 fps.
- Draw calls < 150, треугольников < 200 000, текстурная память < 150 МБ.
- Один кадр логики < 4 мс; генерация чанка < 8 мс.
- Размер бандла < 25 МБ gzip (архив платформы — до 100 МБ).

## Правила
- Маленькие шаги. После каждого — `npm run typecheck` и `npm run build` зелёные.
- Не редактировать чужие зоны без согласования с прорабом. Свои файлы — из брифа.
- Не удалять и не переписывать чужой код «по пути».
- Никаких IP Rockstar: названий, машин, карты, музыки, логотипов.
- Контент: без крови, расчленёнки, наркотиков, реальных брендов. Рейтинг 12+/16+.
- Идентификаторы — English, комментарии и доки — Russian.
- Никаких `any` без комментария, никаких `console.log` в релизных ветках.

## Гигиена процессов (жёстко)
- Не оставлять фоновые процессы. Всё, что запустил, — закрыть в конце (`Stop-Process -Id <pid>`).
- ComfyUI: после батча удалить `ComfyUI/temp/*` и файлы `tmc_*` из `Data/Images`;
  финальные текстуры копировать в `assets/textures/`.
- Перед передачей работы прорабу — остановить dev-сервер, если он не нужен дальше.
- Вне папки проекта — только чтение. Ничего не удалять в `D:\Programs\WebUI`, кроме
  разрешённого кэша, и никогда — чужие результаты.

## Чего не делать
- Не менять стек, не добавлять зависимости без ADR и одобрения прораба.
- Не делать «на будущее»: только текущий этап.
- Не выдумывать требования платформ — сверяться с `09_PLATFORM_QA.md` и офиц. доками.
- Не запускать долгие генерации без явной задачи от прораба.
