# 02 — Ядро: цикл, ввод, физика (core)

## Миссия
Фундамент, на котором стоит всё: игровой цикл, ввод, математика, коллизии, камера,
пулы и шина событий. Твоя зона — `src/core/**`, `src/app/**`, `src/main.ts`.

## Выход
- `src/core/loop.ts` — fixedUpdate 60 Гц + render(alpha), пауза/резюм, защита от спирали смерти.
- `src/core/input.ts` — клавиатура, мышь, геймпад; карта действий, а не сырых клавиш.
- `src/core/math.ts` — vec2, clamp, lerp, angle, OBB, AABB, circle, пересечения, resolve.
- `src/core/rng.ts` — mulberry32 + хелперы (range, pick, weighted).
- `src/core/spatialHash.ts` — вставка/запрос по сетке, снятие устаревших.
- `src/core/registry.ts` — создание/удаление сущностей, компоненты, пулы, запросы.
- `src/core/events.ts` — типизированная шина (без DOM).
- `src/core/camera.ts` — ортокамера сверху, следование с упреждением, тряска, зум, поворот на 90°.
- `src/app/debug.ts` — оверлей: fps, frame ms, draw calls, tris, коллайдеры.

## Требования
- Никаких импортов Three в `systems/**`; Three — только в `render/**`, `core/camera` может
  отдавать параметры, но не лезть в сцену.
- Никаких аллокаций в кадре: переиспользуемые векторы, пулы.
- Детерминизм при одном seed.
- Пауза при `blur`, корректный `visibilitychange`, фикс. шаг не «догоняет» после сна.
- Коллизии: OBB-OBB (SAT), circle-OBB, circle-circle, решатель с restitution ~0.2.
- Пространственный хэш: ячейка 8 м, запрос по прямоугольнику.

## Критерий приёмки (M1–M2)
- Серый полигон, куб-машина едет по WASD, камера следует.
- 300 статических коллайдеров + 50 движущихся: без просадок ниже 60 fps на десктопе.
- Отладочный оверлей показывает бюджеты.
- `npm run typecheck` и `npm run build` зелёные.
